# Trakovo v1.15.3-docker.3

Docker deployment pre-release with a guided Cloudflare Tunnel token prompt.

## Included

- Interactive installs prompt for the Cloudflare Tunnel connector token when Cloudflare ingress is selected
- `--cloudflare-token` and `CLOUDFLARE_TUNNEL_TOKEN` remain available for automated installs

## Important

This is a test-only pre-release and does not replace the existing cPanel deployment.
