# Trakovo

Fleet management platform — bookings, vehicles, drivers, vendors, and dispatch.

Built with Next.js 14, Prisma, SQLite, and Tailwind CSS.

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in your values
npm run dev
```

See `DEV-WORKFLOW.md` for session commit/push workflow and `DEPLOYMENT-CPANEL.md` for production deployment.
